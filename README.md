# UltraDashboard

This repository contains the source planning and execution package for
UltraDashboard V1.

The current repo state focuses on the product instructions and handoff system
that future implementation agents will use.

## Key documents

Start with these files:

- `docs/ultradashboard-spec.md` — full V1 product and technical spec
- `docs/ultradashboard-master-prompt.md` — main implementation prompt for
  ClaudeCode or another strong coding agent
- `docs/ultradashboard-bootstrap-prompt.md` — short prompt to paste into a new
  agent session
- `docs/implementation-tracker.md` — live progress tracker and handoff log
- `docs/ultradashboard-preliminary-architecture.md` — earlier architecture
  draft and validated discovery notes

## Current status

The repository currently contains the full planning package for implementation.
Application code has not been scaffolded yet.

## Next step

The next recommended implementation step is to initialize the `Next.js` App
Router project with TypeScript and begin Phase 0 from the tracker.
